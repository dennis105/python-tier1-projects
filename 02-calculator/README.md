# Calculator

A simple Python console calculator that performs basic arithmetic operations.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling
- Menu-based interface
- Input validation

## Example

```txt
1. Add
2. Subtract
3. Multiply
4. Divide
5. Quit

Enter your choice: 1
Enter first number: 10
Enter second number: 5
Result: 15.0

Enter your choice: 4
Enter first number: 10
Enter second number: 0
Cannot divide by zero.
```

## How to run
```bash
python main.py
```
